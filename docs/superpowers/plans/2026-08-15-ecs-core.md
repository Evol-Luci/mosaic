# ECS Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the Mosaic C++ toolchain and implement the entity/component core (EntityID, generational entity registry, sparse-set component storage, declaration-only system contract) per [RFC 0001](../../rfcs/0001-core-data-model.md) and the [design spec](../specs/2026-08-15-ecs-core-design.md).

**Architecture:** `EntityID` is a dependency-free generational handle in `foundation/core`. Everything else lives in `engine/ecs`: an `EntityRegistry` (slot table + free-list + generation bump, with slot retirement on generation exhaustion), per-type sparse-set component storage behind a type-erased base coordinated by a `ComponentRegistry`, and a declaration-only `System` contract. `engine` depends on `foundation`, never the reverse.

**Tech Stack:** C++20, CMake ≥ 3.20 + CMakePresets, Catch2 v3 via CMake FetchContent, ctest.

## Global Constraints

- **C++ standard:** C++20, `CMAKE_CXX_EXTENSIONS OFF`. Copy verbatim into every CMake target: `target_compile_features(<t> <vis> cxx_std_20)`.
- **Dependency direction:** `engine → foundation` only. `foundation` targets never link or include `engine`. (repo-layout.md)
- **Include style:** all includes are repo-root-relative, e.g. `#include "foundation/core/entity_id.hpp"`. Both library targets set `target_include_directories(... ${CMAKE_SOURCE_DIR})`.
- **Namespaces:** `mosaic::foundation` for foundation code; `mosaic::engine::ecs` for ECS code.
- **EntityID layout:** 64-bit, `(generation << 32) | index` — index in the low 32 bits. Generations start at **1**; `EntityID(0)` is the null handle. Constructor argument order is `EntityID(index, generation)`.
- **Generation sentinel:** `0xFFFFFFFFu` is the **retired** generation, never issued. Valid generations are `1 .. 0xFFFFFFFEu`.
- **Test framework:** Catch2 v3, `#include <catch2/catch_test_macros.hpp>`, link `Catch2::Catch2WithMain`.
- **Commands:** configure `cmake --preset debug`; build `cmake --build --preset debug`; test `ctest --preset debug`.

```cpp
#pragma once

#include <cstddef>
#include <cstdint>
#include <functional>

namespace mosaic::foundation
{

// A 64-bit generational handle: (generation << 32) | index.
// Index occupies the low 32 bits; generation the high 32. Generations start at
// 1, so a zero value is the reserved null/invalid handle.
class EntityID
{
public:
    constexpr EntityID() noexcept : value_(0) {}

    constexpr EntityID(std::uint32_t index, std::uint32_t generation) noexcept
        : value_((static_cast<std::uint64_t>(generation) << 32) | index) {}

    constexpr explicit EntityID(std::uint64_t raw) noexcept : value_(raw) {}

    constexpr std::uint32_t index() const noexcept
    {
        return static_cast<std::uint32_t>(value_ & 0xFFFFFFFFu);
    }

    constexpr std::uint32_t generation() const noexcept
    {
        return static_cast<std::uint32_t>(value_ >> 32);
    }

    constexpr std::uint64_t value() const noexcept { return value_; }

    constexpr explicit operator bool() const noexcept { return value_ != 0; }

    friend constexpr bool operator==(EntityID a, EntityID b) noexcept
    {
        return a.value_ == b.value_;
    }

    friend constexpr bool operator!=(EntityID a, EntityID b) noexcept
    {
        return a.value_ != b.value_;
    }

private:
    std::uint64_t value_;
};

} // namespace mosaic::foundation

template <>
struct std::hash<mosaic::foundation::EntityID>
{
    std::size_t operator()(mosaic::foundation::EntityID id) const noexcept
    {
        return std::hash<std::uint64_t>{}(id.value());
    }
};
```

- [ ] **Step 6: Write the header** — `engine/ecs/entity_registry.hpp`

```cpp
#pragma once

#include <cstddef>
#include <cstdint>
#include <vector>

#include "foundation/core/entity_id.hpp"

namespace mosaic::engine::ecs
{

namespace detail { struct RegistryTestAccess; }

// Slot table of generational entities. create() hands out a slot (recycled from
// a free-list or freshly grown); destroy() bumps the slot's generation so old
// handles no longer validate. On generation exhaustion the slot is retired
// (never recycled) so generational checks can never alias.
class EntityRegistry
{
public:
    // Generation value marking a retired slot; never issued to a live entity.
    static constexpr std::uint32_t kRetiredGeneration = 0xFFFFFFFFu;

    using EntityID = mosaic::foundation::EntityID;

    EntityID create();
    bool destroy(EntityID id);
    bool is_valid(EntityID id) const noexcept;
    std::size_t alive_count() const noexcept { return alive_; }

private:
    friend struct detail::RegistryTestAccess;

    std::vector<std::uint32_t> generations_; // current generation per slot
    std::vector<std::uint32_t> free_list_;   // indices available for recycling
    std::size_t alive_ = 0;
};

} // namespace mosaic::engine::ecs
```

- [ ] **Step 7: Write the implementation** — `engine/ecs/entity_registry.cpp`

```cpp
#include "engine/ecs/entity_registry.hpp"

namespace mosaic::engine::ecs
{

EntityRegistry::EntityID EntityRegistry::create()
{
    std::uint32_t index;
    if (!free_list_.empty())
    {
        index = free_list_.back();
        free_list_.pop_back();
    }
    else
    {
        index = static_cast<std::uint32_t>(generations_.size());
        generations_.push_back(1u); // generations start at 1
    }
    ++alive_;
    return EntityID{index, generations_[index]};
}

bool EntityRegistry::destroy(EntityID id)
{
    if (!is_valid(id))
    {
        return false;
    }

    const std::uint32_t index = id.index();
    const std::uint32_t next = generations_[index] + 1u;
    if (next == kRetiredGeneration)
    {
        // Exhausted: retire the slot. Mark it with the sentinel and do not
        // return it to the free-list, so it is never handed out again.
        generations_[index] = kRetiredGeneration;
    }
    else
    {
        generations_[index] = next;
        free_list_.push_back(index);
    }
    --alive_;
    return true;
}

bool EntityRegistry::is_valid(EntityID id) const noexcept
{
    if (!id)
    {
        return false;
    }
    const std::uint32_t index = id.index();
    if (index >= generations_.size())
    {
        return false;
    }
    return generations_[index] == id.generation();
}

} // namespace mosaic::engine::ecs
```

```cpp
#pragma once

#include <cstddef>
#include <cstdint>
#include <limits>
#include <utility>
#include <vector>

#include "foundation/core/entity_id.hpp"

namespace mosaic::engine::ecs
{

// Entity-keyed sparse set. `sparse_` maps an entity's slot index to a position
// in the packed `dense_` / `components_` arrays. The full EntityID is stored in
// `dense_`, so a lookup with a stale generation does not match.
template <typename T>
class SparseSet
{
public:
    using EntityID = mosaic::foundation::EntityID;

    bool contains(EntityID id) const noexcept { return position_of(id) != kInvalid; }

    T& add(EntityID id, T value)
    {
        const std::uint32_t slot = id.index();
        if (slot >= sparse_.size())
        {
            sparse_.resize(slot + 1u, kInvalid);
        }

        const std::uint32_t pos = sparse_[slot];
        if (pos != kInvalid && pos < dense_.size() && dense_[pos].index() == slot)
        {
            // Overwrite in place; refresh the stored id in case the generation
            // advanced (slot reused without an intervening remove).
            dense_[pos] = id;
            components_[pos] = std::move(value);
            return components_[pos];
        }

        sparse_[slot] = static_cast<std::uint32_t>(dense_.size());
        dense_.push_back(id);
        components_.push_back(std::move(value));
        return components_.back();
    }

    T* get(EntityID id) noexcept
    {
        const std::uint32_t pos = position_of(id);
        return pos == kInvalid ? nullptr : &components_[pos];
    }

    const T* get(EntityID id) const noexcept
    {
        const std::uint32_t pos = position_of(id);
        return pos == kInvalid ? nullptr : &components_[pos];
    }

    bool remove(EntityID id)
    {
        const std::uint32_t pos = position_of(id);
        if (pos == kInvalid)
        {
            return false;
        }

        const std::uint32_t last = static_cast<std::uint32_t>(dense_.size() - 1u);
        if (pos != last)
        {
            dense_[pos] = dense_[last];
            components_[pos] = std::move(components_[last]);
            sparse_[dense_[pos].index()] = pos; // relink the moved element
        }
        dense_.pop_back();
        components_.pop_back();
        sparse_[id.index()] = kInvalid;
        return true;
    }

    std::size_t size() const noexcept { return dense_.size(); }

private:
    static constexpr std::uint32_t kInvalid = std::numeric_limits<std::uint32_t>::max();

    // Returns the dense position for `id`, or kInvalid if absent or the stored
    // generation differs.
    std::uint32_t position_of(EntityID id) const noexcept
    {
        const std::uint32_t slot = id.index();
        if (slot >= sparse_.size())
        {
            return kInvalid;
        }
        const std::uint32_t pos = sparse_[slot];
        if (pos == kInvalid || pos >= dense_.size() || dense_[pos] != id)
        {
            return kInvalid;
        }
        return pos;
    }

    std::vector<std::uint32_t> sparse_;
    std::vector<EntityID> dense_;
    std::vector<T> components_;
};

} // namespace mosaic::engine::ecs
```

```cpp
#pragma once

#include <cstdint>

namespace mosaic::engine::ecs
{

// Minimal reflection shim: a stable, per-type integer id assigned on first use
// within a run. This is type identity only — NOT field reflection. The real
// reflection system (see docs/design/reflection.md) will supply reflection-
// derived TypeIDs and reconcile with this; see the design spec's Risks section.
using ComponentTypeID = std::uint32_t;

namespace detail
{
inline ComponentTypeID next_component_type_id() noexcept
{
    static ComponentTypeID counter = 0;
    return counter++;
}
} // namespace detail

template <typename T>
ComponentTypeID component_type_id() noexcept
{
    static const ComponentTypeID id = detail::next_component_type_id();
    return id;
}

} // namespace mosaic::engine::ecs
```

```cpp
#pragma once

#include <cstddef>
#include <memory>
#include <utility>
#include <vector>

#include "engine/ecs/component_type_id.hpp"
#include "engine/ecs/entity_registry.hpp"
#include "engine/ecs/sparse_set.hpp"
#include "foundation/core/entity_id.hpp"

namespace mosaic::engine::ecs
{

// Type-erased handle to one component type's storage, so the registry can hold
// heterogeneous storages and erase an entity from all of them on destroy.
class IComponentStorage
{
public:
    virtual ~IComponentStorage() = default;
    virtual bool remove(mosaic::foundation::EntityID id) = 0;
    virtual bool contains(mosaic::foundation::EntityID id) const = 0;
};

template <typename T>
class ComponentStorage final : public IComponentStorage
{
public:
    using EntityID = mosaic::foundation::EntityID;

    T& add(EntityID id, T value) { return set_.add(id, std::move(value)); }
    T* get(EntityID id) noexcept { return set_.get(id); }
    bool has(EntityID id) const noexcept { return set_.contains(id); }

    bool remove(EntityID id) override { return set_.remove(id); }
    bool contains(EntityID id) const override { return set_.contains(id); }

private:
    SparseSet<T> set_;
};

// Coordinates per-type component storage with entity validity. Every operation
// rejects handles the owning EntityRegistry no longer considers valid.
class ComponentRegistry
{
public:
    using EntityID = mosaic::foundation::EntityID;

    explicit ComponentRegistry(const EntityRegistry& entities) : entities_(&entities) {}

    template <typename T>
    bool add(EntityID id, T value)
    {
        if (!entities_->is_valid(id))
        {
            return false;
        }
        storage<T>().add(id, std::move(value));
        return true;
    }

    template <typename T>
    T* get(EntityID id)
    {
        if (!entities_->is_valid(id))
        {
            return nullptr;
        }
        ComponentStorage<T>* s = find_storage<T>();
        return s ? s->get(id) : nullptr;
    }

    template <typename T>
    bool has(EntityID id) const
    {
        if (!entities_->is_valid(id))
        {
            return false;
        }
        const ComponentTypeID tid = component_type_id<T>();
        return tid < storages_.size() && storages_[tid] && storages_[tid]->contains(id);
    }

    template <typename T>
    bool remove(EntityID id)
    {
        if (!entities_->is_valid(id))
        {
            return false;
        }
        ComponentStorage<T>* s = find_storage<T>();
        return s ? s->remove(id) : false;
    }

    // Erase an entity from every storage. Call BEFORE EntityRegistry::destroy,
    // while the handle still validates against its storage entries.
    void on_destroy(EntityID id)
    {
        for (std::unique_ptr<IComponentStorage>& storage : storages_)
        {
            if (storage)
            {
                storage->remove(id);
            }
        }
    }

private:
    template <typename T>
    ComponentStorage<T>& storage()
    {
        const ComponentTypeID tid = component_type_id<T>();
        if (tid >= storages_.size())
        {
            storages_.resize(tid + 1u);
        }
        if (!storages_[tid])
        {
            storages_[tid] = std::make_unique<ComponentStorage<T>>();
        }
        return static_cast<ComponentStorage<T>&>(*storages_[tid]);
    }

    template <typename T>
    ComponentStorage<T>* find_storage()
    {
        const ComponentTypeID tid = component_type_id<T>();
        if (tid >= storages_.size() || !storages_[tid])
        {
            return nullptr;
        }
        return static_cast<ComponentStorage<T>*>(storages_[tid].get());
    }

    const EntityRegistry* entities_;
    std::vector<std::unique_ptr<IComponentStorage>> storages_; // indexed by ComponentTypeID
};

} // namespace mosaic::engine::ecs
```

```cpp
#pragma once

#include <vector>

#include "engine/ecs/component_type_id.hpp"

namespace mosaic::engine::ecs
{

// Declares which component types a system reads and writes. Declaration only —
// scheduling and execution are a later concern (the job system). Systems hold no
// per-entity state; state lives in components.
class ComponentAccess
{
public:
    template <typename T>
    ComponentAccess& reads()
    {
        reads_.push_back(component_type_id<T>());
        return *this;
    }

    template <typename T>
    ComponentAccess& writes()
    {
        writes_.push_back(component_type_id<T>());
        return *this;
    }

    const std::vector<ComponentTypeID>& read_set() const noexcept { return reads_; }
    const std::vector<ComponentTypeID>& write_set() const noexcept { return writes_; }

private:
    std::vector<ComponentTypeID> reads_;
    std::vector<ComponentTypeID> writes_;
};

class System
{
public:
    virtual ~System() = default;

    const ComponentAccess& access() const noexcept { return access_; }

protected:
    ComponentAccess access_; // subclasses declare their access in their constructor
};

} // namespace mosaic::engine::ecs
```
