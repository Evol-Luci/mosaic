# foundation/logging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a leveled, categorized, thread-safe logging facility in the `foundation/` tier (issue [#33](https://github.com/Evol-Luci/mosaic/issues/33)).

**Architecture:** One header, `foundation/logging/log.hpp`. A complete `Logger` class (sink list + min-level + mutex) holds the state; a process-global free-function surface (`log::info(cat, fmt, args...)`) forwards to a single function-local-static default `Logger`. Messages format via `std::format`; a single mutex around sink dispatch guarantees no torn lines. Header-only.

**Tech Stack:** C++20 (`std::format`, `std::atomic`), Catch2 v3, CMake presets.

## Global Constraints

- **Tier contract:** `foundation/logging` depends only on the standard library — nothing else in `foundation/`, nothing above it. (per [ARCHITECTURE.md](../../architecture/ARCHITECTURE.md))
- **Namespace:** `mosaic::foundation::log`.
- **Header-first:** header-only, `inline` free functions + function-local-static global. No `.cpp`.
- **C++ standard:** C++20 (`cxx_std_20`), no compiler extensions.
- **Test tag:** every test case uses the `[logging]` Catch2 tag.
- **Sink contract:** `Sink::write` is `noexcept` — logging must never throw into a caller.
- **Message order:** sinks fire in registration order.
- **Default min-level:** `Level::Info`.

**Build & test commands (used throughout):**
- Configure (first time only): `cmake --preset debug`
- Build: `cmake --build --preset debug`
- Run just the logging tests: `./build/debug/tests/mosaic_unit_tests "[logging]"`
- Run the full suite: `ctest --preset debug`

Create `foundation/logging/log.hpp`:

```cpp
#pragma once

#include <atomic>
#include <memory>
#include <mutex>
#include <string_view>
#include <utility>
#include <vector>

namespace mosaic::foundation::log
{

// Severity levels, ordered ascending so the min-level filter is a `>=` compare.
enum class Level
{
    Trace,
    Debug,
    Info,
    Warn,
    Error
};

constexpr std::string_view to_string(Level level)
{
    switch (level)
    {
    case Level::Trace: return "TRACE";
    case Level::Debug: return "DEBUG";
    case Level::Info:  return "INFO";
    case Level::Warn:  return "WARN";
    case Level::Error: return "ERROR";
    }
    return "?";
}

// The immutable value handed to a sink. `message` is already formatted; both
// string views are valid only for the duration of the sink's `write` call.
struct Record
{
    Level            level;
    std::string_view category;
    std::string_view message;
};

// A destination for log records. `write` is noexcept by contract: logging can
// happen during error handling, so a sink must never throw into the caller.
class Sink
{
public:
    virtual ~Sink() = default;
    virtual void write(const Record&) noexcept = 0;
};

// The complete logging core: a set of sinks, a minimum level, and a mutex that
// serializes dispatch so concurrent logs never produce torn/interleaved output.
//
// v0.1 exposes only the process-global free-function surface below; this class
// is instantiable (and directly unit-tested) so a future version can promote it
// to a public, injectable API without changing any call site.
class Logger
{
public:
    void add_sink(std::shared_ptr<Sink> sink)
    {
        std::lock_guard<std::mutex> lock(mutex_);
        sinks_.push_back(std::move(sink));
    }

    void clear_sinks()
    {
        std::lock_guard<std::mutex> lock(mutex_);
        sinks_.clear();
    }

    void set_min_level(Level level)
    {
        min_level_.store(level, std::memory_order_relaxed);
    }

    void log(Level level, std::string_view category, std::string_view message)
    {
        // Drop below-threshold messages without taking the lock.
        if (level < min_level_.load(std::memory_order_relaxed))
        {
            return;
        }
        const Record record{level, category, message};
        std::lock_guard<std::mutex> lock(mutex_);
        for (auto& sink : sinks_)
        {
            sink->write(record);
        }
    }

private:
    std::vector<std::shared_ptr<Sink>> sinks_;
    std::atomic<Level>                 min_level_{Level::Info};
    std::mutex                         mutex_;
};

} // namespace mosaic::foundation::log
```

```cpp
namespace log = mosaic::foundation::log;

{
class CapturingSink : public log::Sink
{
public:

    {
        log::Level  level;
        std::string category;
        std::string message;
```

```cpp
// The default console sink: writes "[LEVEL] category: message\n" to std::cerr
// (unbuffered, so lines survive a crash). Output failures are swallowed to keep
// the noexcept contract.
class ConsoleSink : public Sink
{
public:
    void write(const Record& record) noexcept override
    {
        std::cerr << '[' << to_string(record.level) << "] " << record.category
                  << ": " << record.message << '\n';
    }
};

// The process-global default logger. A function-local static: constructed on
// first use, destroyed at program exit, no static-init-order hazard.
inline Logger& default_logger()
{
    static Logger logger;
    return logger;
}

inline void set_min_level(Level level)
{
    default_logger().set_min_level(level);
}

inline void add_sink(std::shared_ptr<Sink> sink)
{
    default_logger().add_sink(std::move(sink));
}

inline void clear_sinks()
{
    default_logger().clear_sinks();
}

template <class... A>
void trace(std::string_view category, std::format_string<A...> fmt, A&&... args)
{
    default_logger().log(Level::Trace, category,
                         std::format(fmt, std::forward<A>(args)...));
}

template <class... A>
void debug(std::string_view category, std::format_string<A...> fmt, A&&... args)
{
    default_logger().log(Level::Debug, category,
                         std::format(fmt, std::forward<A>(args)...));
}

template <class... A>
void info(std::string_view category, std::format_string<A...> fmt, A&&... args)
{
    default_logger().log(Level::Info, category,
                         std::format(fmt, std::forward<A>(args)...));
}

template <class... A>
void warn(std::string_view category, std::format_string<A...> fmt, A&&... args)
{
    default_logger().log(Level::Warn, category,
                         std::format(fmt, std::forward<A>(args)...));
}

template <class... A>
void error(std::string_view category, std::format_string<A...> fmt, A&&... args)
{
    default_logger().log(Level::Error, category,
                         std::format(fmt, std::forward<A>(args)...));
}
```

> Note: `std::format(...)` returns a temporary `std::string`; it is bound to the `message` `string_view` parameter of `log()` and stays alive for the full duration of that call, so the view never dangles.

```cpp
#include <memory>
#include <mutex>
#include <string>
#include <thread>
#include <vector>

#include <catch2/catch_test_macros.hpp>

#include "foundation/logging/log.hpp"

using mosaic::foundation::log::Level;
using mosaic::foundation::log::Logger;
using mosaic::foundation::log::Record;
using mosaic::foundation::log::Sink;

namespace
{
// Appends each record's message as one whole entry under its own lock. If the
// Logger did not serialize dispatch, concurrent writers could corrupt the
// vector (a data race) or split a record; the count and the intact strings
// prove neither happened.
class CountingSink : public Sink
{
public:
    std::vector<std::string> lines;

    void write(const Record& record) noexcept override
    {
        std::lock_guard<std::mutex> lock(mutex_);
        lines.emplace_back(record.message);
    }

private:
    std::mutex mutex_;
};
} // namespace

TEST_CASE("concurrent logging loses no records and tears no lines", "[logging]")
{
    Logger logger;
    auto sink = std::make_shared<CountingSink>();
    logger.add_sink(sink);
    logger.set_min_level(Level::Trace);

    constexpr int thread_count = 8;
    constexpr int per_thread = 500;
    const std::string payload = "intact-line-payload";

    std::vector<std::thread> threads;
    for (int t = 0; t < thread_count; ++t)
    {
        threads.emplace_back([&logger, &payload] {
            for (int i = 0; i < per_thread; ++i)
            {
                logger.log(Level::Info, "concurrency", payload);
            }
        });
    }
    for (auto& thread : threads)
    {
        thread.join();
    }

    REQUIRE(sink->lines.size() == static_cast<std::size_t>(thread_count * per_thread));
    for (const auto& line : sink->lines)
    {
        REQUIRE(line == payload); // no torn/interleaved content
    }
}
```
