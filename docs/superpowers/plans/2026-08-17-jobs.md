# foundation/jobs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A minimal thread-pool task system in the `foundation/` tier: `ThreadPool::submit` returning `std::future<void>`, and a blocking `parallel_for` (issue [#34](https://github.com/Evol-Luci/mosaic/issues/34)).

**Architecture:** A compiled `mosaic_jobs` static library (mirroring `mosaic_serialization`), stdlib threads only. `ThreadPool` owns N worker threads pulling FIFO from a mutex/condvar-guarded queue; `submit` wraps a `std::packaged_task`; `parallel_for` chunks a range across the pool and blocks on an internal latch. Destruction drains the queue then joins.

**Tech Stack:** C++20 (`<thread>`, `<future>`, `<condition_variable>`, `<atomic>`), system Threads, Catch2 v3.

## Global Constraints

- **Tier:** `foundation/jobs` depends only on the standard library + the system Threads library — nothing else in `foundation/`, nothing above it. No third-party dependency.
- **Namespace:** `mosaic::foundation::jobs`.
- **Compiled module:** a `mosaic_jobs` STATIC library (not header-only), following the `mosaic_serialization` pattern.
- **Test tag:** every test case uses the `[jobs]` Catch2 tag.
- **C++ standard:** `cxx_std_20`, no compiler extensions.
- **Handle type:** `submit` returns `std::future<void>`; a throwing task is captured into the future (rethrown on `.get()`).
- **`parallel_for` blocks** until all chunks complete; an exception thrown by any body is **rethrown from the calling thread** after all chunks finish; empty/inverted range is a no-op.
- **thread_count** clamps to `>= 1`.
- **Clean shutdown:** the destructor drains all queued tasks, then joins every worker — no detached/leaked threads, no unfulfilled future.

**Build & test commands (used throughout):**
- Configure (first time / after CMake edits): `cmake --preset debug`
- Build: `cmake --build --preset debug`
- Run jobs tests: `./build/debug/tests/mosaic_unit_tests "[jobs]"`
- Full suite: `ctest --preset debug`

- [ ] **Step 4: Write the header**

Create `foundation/jobs/thread_pool.hpp`:

```cpp
#pragma once

#include <condition_variable>
#include <cstddef>
#include <functional>
#include <future>
#include <mutex>
#include <queue>
#include <thread>
#include <vector>

namespace mosaic::foundation::jobs
{

// A minimal fixed-size thread pool. Workers pull tasks FIFO from a shared queue.
// submit() returns a future fulfilled when the task finishes; parallel_for()
// (added alongside) blocks until a whole range is processed. Destruction drains
// every queued task, then joins — no detached threads, no unfulfilled future.
class ThreadPool
{
public:
    // Spins up `thread_count` workers, clamped to >= 1.
    explicit ThreadPool(unsigned thread_count = std::thread::hardware_concurrency());
    ~ThreadPool();

    ThreadPool(const ThreadPool&) = delete;
    ThreadPool& operator=(const ThreadPool&) = delete;

    // Enqueue a task; the returned future completes when it runs (or carries the
    // task's exception, rethrown on get()).
    std::future<void> submit(std::function<void()> task);

    // Split [begin, end) into up to thread_count chunks (respecting `grain`), run
    // `body(i)` over each index across the pool, and block until all complete.
    // Empty/inverted range is a no-op. The first exception thrown by any body is
    // rethrown from the calling thread after all chunks finish.
    void parallel_for(std::size_t begin, std::size_t end,
                      const std::function<void(std::size_t)>& body, std::size_t grain = 1);

    unsigned thread_count() const noexcept { return static_cast<unsigned>(workers_.size()); }

private:
    void worker_loop();

    std::vector<std::thread>          workers_;
    std::queue<std::function<void()>> tasks_;
    std::mutex                        mutex_;
    std::condition_variable           cv_;
    bool                              stopping_ = false;
};

} // namespace mosaic::foundation::jobs
```

- [ ] **Step 5: Write the implementation (submit + lifecycle only)**

Create `foundation/jobs/thread_pool.cpp`:

```cpp
#include "foundation/jobs/thread_pool.hpp"

#include <algorithm>
#include <memory>
#include <utility>

namespace mosaic::foundation::jobs
{

ThreadPool::ThreadPool(unsigned thread_count)
{
    const unsigned n = std::max(1u, thread_count);
    workers_.reserve(n);
    for (unsigned i = 0; i < n; ++i)
    {
        workers_.emplace_back([this] { worker_loop(); });
    }
}

ThreadPool::~ThreadPool()
{
    {
        std::lock_guard<std::mutex> lock(mutex_);
        stopping_ = true;
    }
    cv_.notify_all();
    for (auto& worker : workers_)
    {
        worker.join();
    }
}

std::future<void> ThreadPool::submit(std::function<void()> task)
{
    // packaged_task is move-only; wrap in shared_ptr so the queued std::function
    // (which requires a copyable target) can hold it.
    auto packaged = std::make_shared<std::packaged_task<void()>>(std::move(task));
    std::future<void> future = packaged->get_future();
    {
        std::lock_guard<std::mutex> lock(mutex_);
        tasks_.push([packaged] { (*packaged)(); });
    }
    cv_.notify_one();
    return future;
}

void ThreadPool::worker_loop()
{
    for (;;)
    {
        std::function<void()> task;
        {
            std::unique_lock<std::mutex> lock(mutex_);
            cv_.wait(lock, [this] { return stopping_ || !tasks_.empty(); });
            if (tasks_.empty())
            {
                // Woken only because stopping_ and the queue is drained -> exit.
                return;
            }
            task = std::move(tasks_.front());
            tasks_.pop();
        }
        task();
    }
}

} // namespace mosaic::foundation::jobs
```

```cpp
void ThreadPool::parallel_for(std::size_t begin, std::size_t end,
                              const std::function<void(std::size_t)>& body,
                              std::size_t grain)
{
    if (begin >= end)
    {
        return;
    }
    if (grain == 0)
    {
        grain = 1;
    }

    const std::size_t total = end - begin;
    const std::size_t max_chunks = (total + grain - 1) / grain;        // ceil(total/grain)
    const std::size_t chunk_count = std::min<std::size_t>(workers_.size(), max_chunks);
    const std::size_t per_chunk = (total + chunk_count - 1) / chunk_count; // ceil

    // The latch lives on this frame, which outlives the chunk tasks because we
    // block below until every chunk has decremented `remaining`.
    struct Latch
    {
        std::mutex              m;
        std::condition_variable cv;
        std::size_t             remaining;
        std::exception_ptr      error;
    };
    Latch latch;
    latch.remaining = chunk_count;

    for (std::size_t c = 0; c < chunk_count; ++c)
    {
        const std::size_t chunk_begin = begin + c * per_chunk;
        const std::size_t chunk_end = std::min(chunk_begin + per_chunk, end);
        {
            std::lock_guard<std::mutex> lock(mutex_);
            tasks_.push([&latch, &body, chunk_begin, chunk_end] {
                std::exception_ptr err;
                try
                {
                    for (std::size_t i = chunk_begin; i < chunk_end; ++i)
                    {
                        body(i);
                    }
                }
                catch (...)
                {
                    err = std::current_exception();
                }
                bool last = false;
                {
                    std::lock_guard<std::mutex> llock(latch.m);
                    if (err && !latch.error)
                    {
                        latch.error = err;
                    }
                    last = (--latch.remaining == 0);
                }
                if (last)
                {
                    latch.cv.notify_one();
                }
            });
        }
        cv_.notify_one();
    }

    std::unique_lock<std::mutex> lock(latch.m);
    latch.cv.wait(lock, [&latch] { return latch.remaining == 0; });
    if (latch.error)
    {
        std::rethrow_exception(latch.error);
    }
}
```
