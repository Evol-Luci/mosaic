# Audio subsystem A1 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the Audio pillar — a neutral `AudioBackend` interface, reflected `AudioSource`/`AudioListener` components, and an `AudioSystem` that drives the backend from ECS state — headless, deterministic, no device dependency.

**Architecture:** Mirrors the physics/scripting neutral-backend pattern. `AudioSystem` (injected `std::unique_ptr<AudioBackend>`) edge-triggers `play`/`stop` on each `AudioSource.playing`, pushes gain/pitch/position, and sets the listener from an `AudioListener` entity's Transform. Voices are transient state keyed by entity id (the `NavigationSystem`/`ParticleSystem` pattern); the system writes nothing back to components. Proven with a recording `FakeAudioBackend` (like `FakeRenderDevice`). No real device backend, not wired into `setup_runtime` (both deferred).

**Tech Stack:** C++20, header-only engine modules, Catch2 (FetchContent), CMake/CTest. No new dependencies.

**Spec:** [docs/superpowers/specs/2026-09-06-audio-a1-design.md](2026-09-06-audio-a1-design.md)

## Global Constraints

- C++20; header-only under `engine/audio/`; no new third-party dependency; no real audio device.
- `AudioSystem` never mutates components; voices are transient, keyed by entity id; prune stops a destroyed entity's voice.
- Play is **edge-triggered** on `AudioSource.playing` (false→true starts, true→false stops); no polling of real audio time, so ticks are deterministic.
- Not added to `setup_runtime` in A1 (no device backend yet).
- Persisted identity is the component name (`"AudioSource"`, `"AudioListener"`).
- New tests tagged `[audio]`, added to `tests/CMakeLists.txt`. Build target `mosaic_unit_tests`; preset build dir `build/debug`.
- `World::tick` runs systems **before** committing deferred destructions, so an entity destroyed via `destroy_entity` is still seen during that tick and is pruned on the *following* tick.

#pragma once

#include <cstdint>

#include "foundation/math/vec3.hpp"
#include "foundation/serialization/reference.hpp" // AssetID

namespace mosaic::engine::audio
{
using mosaic::foundation::math::Vec3;
using mosaic::foundation::serialization::AssetID;

// Handle to a playing sound instance. 0 = none/invalid.
using VoiceId = std::uint64_t;

// Listener (the "ears") pose for spatialization.
struct ListenerState
{
    Vec3 position{};
    Vec3 forward{0.0f, 0.0f, -1.0f};
    Vec3 up{0.0f, 1.0f, 0.0f};
};

// Neutral audio backend. A device module (miniaudio/OpenAL/...) implements this
// later; A1 ships only a recording fake used in tests. Concrete device types never
// leak past this wall.
class AudioBackend
{
public:
    virtual ~AudioBackend() = default;
    virtual VoiceId play(AssetID clip, float gain, float pitch, bool looping) = 0;
    virtual void    stop(VoiceId voice) = 0;
    virtual void    set_gain(VoiceId voice, float gain) = 0;
    virtual void    set_pitch(VoiceId voice, float pitch) = 0;
    virtual void    set_voice_position(VoiceId voice, const Vec3& position) = 0;
    virtual bool    is_playing(VoiceId voice) const = 0;
    virtual void    set_listener(const ListenerState& listener) = 0;
};
} // namespace mosaic::engine::audio

    visitor.member("pitch", s.pitch);

    visitor.member("playing", s.playing);
    visitor.member("spatial", s.spatial);

{
};

}

- [ ] **Step 1: Create `engine/audio/audio_system.hpp`**

```cpp
#pragma once

#include <cstdint>
#include <memory>
#include <unordered_map>
#include <unordered_set>

#include "engine/audio/audio_backend.hpp"
#include "engine/audio/audio_components.hpp"
#include "engine/ecs/system.hpp"
#include "engine/transform/transform.hpp"
#include "engine/world/world.hpp"
#include "foundation/core/entity_id.hpp"

namespace mosaic::engine::audio
{
// Drives AudioSources: starts/stops a backend voice on the source's `playing` edge,
// pushes gain/pitch changes and (for spatial sources) the entity's position, and sets
// the listener pose from the AudioListener entity's Transform. The backend is injected;
// this system depends only on the neutral interface, never on a device module. Writes
// nothing back to components; voices are transient state keyed by entity id.
class AudioSystem : public ecs::System
{
public:
    explicit AudioSystem(std::unique_ptr<AudioBackend> backend) : backend_(std::move(backend)) {}

    void update(World& world, float /*dt*/) override
    {
        if (backend_ == nullptr) { return; }

        // Listener: the first entity with AudioListener + Transform.
        bool listener_done = false;
        world.for_each<AudioListener>(
            [&](mosaic::foundation::EntityID e, AudioListener&)
            {
                if (listener_done) { return; }
                if (auto* tf = world.get_component<transform::Transform>(e))
                {
                    backend_->set_listener(ListenerState{tf->position, Vec3{0.0f, 0.0f, -1.0f},
                                                         Vec3{0.0f, 1.0f, 0.0f}});
                    listener_done = true;
                }
            });

        std::unordered_set<std::uint64_t> seen;
        world.for_each<AudioSource>(
            [&](mosaic::foundation::EntityID e, AudioSource& src)
            {
                const std::uint64_t id = e.value();
                seen.insert(id);
                Voice& st = voices_[id]; // default-constructs on first sight

                if (src.playing && !st.was_playing)
                {
                    st.id    = backend_->play(src.clip, src.gain, src.pitch, src.looping);
                    st.gain  = src.gain;
                    st.pitch = src.pitch;
                }
                else if (!src.playing && st.was_playing)
                {
                    if (st.id != 0) { backend_->stop(st.id); }
                    st.id = 0;
                }

                if (st.id != 0)
                {
                    if (src.gain != st.gain) { backend_->set_gain(st.id, src.gain); st.gain = src.gain; }
                    if (src.pitch != st.pitch) { backend_->set_pitch(st.id, src.pitch); st.pitch = src.pitch; }
                    if (src.spatial)
                    {
                        if (auto* tf = world.get_component<transform::Transform>(e))
                        {
                            backend_->set_voice_position(st.id, tf->position);
                        }
                    }
                }

                st.was_playing = src.playing;
            });

        // Prune voices for emitters that no longer exist; stop any that were playing.
        for (auto it = voices_.begin(); it != voices_.end();)
        {
            if (seen.count(it->first) != 0)
            {
                ++it;
            }
            else
            {
                if (it->second.id != 0) { backend_->stop(it->second.id); }
                it = voices_.erase(it);
            }
        }
    }

private:
    struct Voice
    {
        VoiceId id          = 0;
        bool    was_playing = false;
        float   gain        = 1.0f;
        float   pitch       = 1.0f;
    };

    std::unique_ptr<AudioBackend>            backend_;
    std::unordered_map<std::uint64_t, Voice> voices_;
};
} // namespace mosaic::engine::audio
```

#include <catch2/catch_approx.hpp>
#include <catch2/catch_test_macros.hpp>

#include <memory>
#include <vector>

#include "engine/audio/audio_backend.hpp"
#include "engine/audio/audio_components.hpp"
#include "engine/audio/audio_system.hpp"
#include "engine/transform/transform.hpp"
#include "engine/world/world.hpp"

using Catch::Approx;
using mosaic::engine::World;
using mosaic::engine::audio::AudioBackend;
using mosaic::engine::audio::AudioListener;
using mosaic::engine::audio::AudioSource;
using mosaic::engine::audio::AudioSystem;
using mosaic::engine::audio::ListenerState;
using mosaic::engine::audio::VoiceId;
using mosaic::engine::transform::Transform;
using mosaic::foundation::math::Vec3;
using mosaic::foundation::serialization::AssetID;

// Records every backend call so tests can assert what the AudioSystem drove.
class FakeAudioBackend : public AudioBackend
{
public:
    struct PlayCall { AssetID clip; float gain; float pitch; bool looping; };
    std::vector<PlayCall>                 plays;
    std::vector<VoiceId>                  stops;
    std::vector<std::pair<VoiceId, float>> gains;
    std::vector<std::pair<VoiceId, float>> pitches;
    std::vector<std::pair<VoiceId, Vec3>>  positions;
    bool                                   listener_set = false;
    ListenerState                          listener{};

    VoiceId play(AssetID clip, float gain, float pitch, bool looping) override
    {
        plays.push_back(PlayCall{clip, gain, pitch, looping});
        return next_voice_++;
    }
    void stop(VoiceId voice) override { stops.push_back(voice); }
    void set_gain(VoiceId voice, float gain) override { gains.emplace_back(voice, gain); }
    void set_pitch(VoiceId voice, float pitch) override { pitches.emplace_back(voice, pitch); }
    void set_voice_position(VoiceId voice, const Vec3& position) override
    {
        positions.emplace_back(voice, position);
    }
    bool is_playing(VoiceId) const override { return true; }
    void set_listener(const ListenerState& l) override { listener_set = true; listener = l; }

private:
    VoiceId next_voice_ = 1;
};
