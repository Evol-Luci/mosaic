# UI U3 — HUD Images / Sprites Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render HUD sprites — a reflected `UiImage` draws a textured, tinted, alpha-blended quad stretched to an anchored screen rect.

**Architecture:** `UiImage` reuses U1's `resolve_rect` placement plus a texture `AssetID` + tint. `RenderSystem` runs an image pass after the panel pass, resolving the texture via the existing `texture_cache_`, and submits `UiImageQuad`s through a new `draw_ui_image` seam. A Vulkan screen-space textured pipeline (U1 `ui` pipeline + the decal texture descriptor) draws them.

**Tech Stack:** C++20, Catch2, CMake, Vulkan (module-walled), reflection.

**Spec:** `docs/superpowers/specs/2026-09-08-ui-u3-images-design.md`

**Base branch:** `claude/ui-u3-images` (off `main` = U1 + U2a; `cmake --preset debug` configured).

## Global Constraints

- **Module wall:** no `Vk*` above `modules/`. Neutral UI types are backend-free. The pipeline lives only in `modules/render_vulkan`.
- **Build convention:** presets into `build/debug/`. Build: `cmake --build --preset debug [--target <t>]`. Test binary: `./build/debug/tests/mosaic_unit_tests "[tag]"` (Catch2 tag; comma = OR). Full suite: `ctest --preset debug`. App: `./build/debug/app/mosaic`. Do **not** use `cmake --build build` or `./build/app/...`. **Transient link failures:** the ~170 MB test binary intermittently fails at the LINK step under memory pressure (`ld` error, "Deleting file 'tests/mosaic_unit_tests'", `make ... Error 2`) with **no compiler error** — if a build fails, `grep -iE "error:|error C[0-9]|undefined reference"` the output; if empty, just re-run the build (up to ~3×). **After changing a header used by the app (`render_system.hpp`, `demo_scene.hpp`, `render_device.hpp`), rebuild the `mosaic` target before any `mosaic run` check.**
- **Coordinate convention:** normalized screen space, origin top-left, x right, y down, `[0,1]` (U1 `resolve_rect`).
- **Reflection field types:** `AssetID` (like `Decal.texture` / `Material.texture`) and `Vec2`/`Vec3`/`int`/`float` are all supported reflected members.
- **Texture descriptor:** the Vulkan texture sampler is `set = 0, binding = 0` via `texture_set_layout_` (decal/material convention); `create_texture(Image)` returns a 1-based handle stored in `textures_`, and `textures_[handle-1].set` is its descriptor.

Create `engine/ui/ui_image.hpp`:

```cpp
#pragma once

#include "foundation/math/vec2.hpp"
#include "foundation/math/vec3.hpp"
#include "foundation/serialization/reference.hpp" // AssetID

namespace mosaic::engine::ui
{
using mosaic::foundation::math::Vec2;
using mosaic::foundation::math::Vec3;

// A screen-space HUD sprite: `texture` stretched to an anchored rect, tinted and
// alpha-blended. anchor is an int cast to ui::Anchor (clamped to TopLeft out of range).
// pos is a normalized offset from the anchor; size is a fraction of the screen. tint
// multiplies the texture rgb; alpha multiplies the texture alpha. Script-mutable.
struct UiImage
{
    mosaic::foundation::serialization::AssetID texture;
    int   anchor = 0;
    Vec2  pos    = Vec2{0.0f, 0.0f};
    Vec2  size   = Vec2{0.1f, 0.1f};
    Vec3  tint   = Vec3{1.0f, 1.0f, 1.0f};
    float alpha  = 1.0f;
    int   order  = 0;
};

template <class V>
void reflect(V& visitor, UiImage& i)
{
    visitor.member("texture", i.texture);
    visitor.member("anchor", i.anchor);
    visitor.member("pos", i.pos);
    visitor.member("size", i.size);
    visitor.member("tint", i.tint);
    visitor.member("alpha", i.alpha);
    visitor.member("order", i.order);
}
} // namespace mosaic::engine::ui
```

- [ ] **Step 1: Write the shaders**

Create `modules/render_vulkan/shaders/ui_image.vert`:

```glsl
#version 450

layout(push_constant) uniform Push {
    vec4 rect;   // x, y, w, h in [0,1], top-left origin
    vec4 tint;   // rgb + alpha
} pc;

layout(location = 0) out vec2 v_uv;
layout(location = 1) out vec4 v_tint;

vec2 corner(int i) {
    if (i == 0) return vec2(0.0, 0.0);
    if (i == 1) return vec2(1.0, 0.0);
    if (i == 2) return vec2(0.0, 1.0);
    if (i == 3) return vec2(1.0, 0.0);
    if (i == 4) return vec2(1.0, 1.0);
    return vec2(0.0, 1.0);
}

void main() {
    vec2 c = corner(gl_VertexIndex);
    float nx = pc.rect.x + c.x * pc.rect.z;
    float ny = pc.rect.y + c.y * pc.rect.w;
    gl_Position = vec4(nx * 2.0 - 1.0, ny * 2.0 - 1.0, 0.0, 1.0);
    v_uv = c;           // full-texture UV 0..1
    v_tint = pc.tint;
}
```

Create `modules/render_vulkan/shaders/ui_image.frag`:

```glsl
#version 450

layout(set = 0, binding = 0) uniform sampler2D tex;

layout(location = 0) in vec2 v_uv;
layout(location = 1) in vec4 v_tint;
layout(location = 0) out vec4 o_color;

void main() {
    vec4 t = texture(tex, v_uv);
    o_color = vec4(t.rgb * v_tint.rgb, t.a * v_tint.a);
}
```

```cpp
    void draw_ui_image(const std::vector<mosaic::engine::render::UiImageQuad>& quads,
                       mosaic::engine::render::TextureHandle texture) override
    {
        if (quads.empty()) { return; }
        if (!viewport_pass_open_) { ensure_swapchain_pass(); }
        if (frame_skipped_ || textures_.empty()) { return; }

        const std::uint32_t tex_index =
            (texture == 0 || texture > textures_.size()) ? 0u : texture - 1u;
        VkPipeline pipe = viewport_pass_open_ ? vp_ui_image_pipeline_ : ui_image_pipeline_;
        vkCmdBindPipeline(cmd_[frame_], VK_PIPELINE_BIND_POINT_GRAPHICS, pipe);
        vkCmdBindDescriptorSets(cmd_[frame_], VK_PIPELINE_BIND_POINT_GRAPHICS,
                                ui_image_pipeline_layout_, 0, 1, &textures_[tex_index].set, 0, nullptr);
        for (const auto& q : quads)
        {
            UiImagePush pc{};
            pc.rect[0] = q.rect.x; pc.rect[1] = q.rect.y; pc.rect[2] = q.rect.w; pc.rect[3] = q.rect.h;
            pc.tint[0] = q.tint.x; pc.tint[1] = q.tint.y; pc.tint[2] = q.tint.z; pc.tint[3] = q.alpha;
            vkCmdPushConstants(cmd_[frame_], ui_image_pipeline_layout_,
                               VK_SHADER_STAGE_VERTEX_BIT | VK_SHADER_STAGE_FRAGMENT_BIT,
                               0, sizeof(UiImagePush), &pc);
            vkCmdDraw(cmd_[frame_], 6, 1, 0, 0);
        }
    }
```
