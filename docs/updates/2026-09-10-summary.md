### 3. UI Subsystem — Screen-Space HUD Viewport Correction (PR [#135](https://github.com/Evol-Luci/mosaic/pull/135))

* **Problem & Root Cause:**
  * Vulkan swapchain and offscreen passes utilize negative-height viewports (`height = -viewport_h`) to maintain standard Y-up 3D Cartesian coordinates.
  * The screen-space UI vertex shaders (`ui.vert`, `ui_image.vert`, `ui_text.vert`) mapped normalized coordinates via `gl_Position.y = ny * 2 - 1`. The negative-height viewport subsequently inverted the Y-axis, causing 2D HUD elements to render upside-down.
* **Fix & Verification:**
  * Re-mapped normalized Y coordinates in all three shaders to `clip.y = 1.0 - 2.0 * ny`.
  * Preserved top-left origin ($0, 0$) at the physical top-left of the display window while leaving 3D world-space pipelines unaffected.

    * Guarantees deterministic message delivery, channel distinction, and immediate disconnection detection in headless test runs.

    * Defined `MessageType` enum (`Hello = 1`, `Welcome = 2`).
    * Added portable little-endian serialization helpers (`put_u32`, `get_u32`).
    * Added encoder/decoder routines for `Hello` (greeting) and `Welcome` (assigning 32-bit session ID).
  * **Network Events ([`engine/net/network_event.hpp`](../../engine/net/network_event.hpp)):**
    * Defined `PeerJoined { session_id }`, `PeerLeft { session_id }`, `SessionEstablished { session_id }`, and `Disconnected` event types dispatched via `EventBus`.
  * **ECS NetworkSystem ([`engine/net/network_system.hpp`](../../engine/net/network_system.hpp)):**
    * Implemented `NetworkSystem` running in `World::tick()`.
    * Implemented `Role::Server`: responds to client `Hello` messages by allocating monotonic session IDs (starting at 1), returning `Welcome` envelopes, and dispatching `PeerJoined` / `PeerLeft` events.
    * Implemented `Role::Client`: sends `Hello` upon connection, waits for `Welcome`, adopts server-assigned ID, and dispatches `SessionEstablished`.
